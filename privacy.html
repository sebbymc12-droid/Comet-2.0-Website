Comet 2.0 Privacy

Last updated: 18 September 2026

1. TL;DR

Comet 2.0 is a personal Discord bot and passion project created and maintained by @comet_saturn.

Comet is currently used for a single Discord community and is provided free of charge. It is not intended to be a commercial service.

Comet only processes information that it needs to provide its features. It is designed to keep as little information as reasonably possible and does not intentionally build a permanent database of users, messages, or normal activity.

2. What Comet May Process

Because Comet operates through the Discord API, Discord may provide Comet with information needed for the bot to function.

Depending on which features are being used, this may include:

  • Discord user IDs, usernames, and display information
  • Server, channel, and role information
  • Message content when required for enabled features
  • Command options, arguments, and other command input
  • Information required to perform moderation actions
  • Temporary information required for features such as PingWarn and cooldowns
  • Other Discord-provided information reasonably necessary for an enabled feature

The exact information used can vary depending on the features enabled in the community.

3. Why Comet Uses This Information

Information is used to provide Comet's Discord features and respond to users.

This can include things such as:

  • Processing commands and sending responses
  • Running fun, game, and utility commands
  • Running SSU and announcement features
  • Providing moderation tools
  • Running PingWarn and similar server features
  • Checking permissions before allowing certain actions
  • Performing actions requested through authorised commands

Comet does not intentionally use this information for advertising, profiling, analytics, or unrelated purposes.

4. Message Content and Prefix Commands

Comet supports prefix commands beginning with c!. Message Content is also required for certain enabled features, such as PingWarn.

When necessary, Comet temporarily reads message content so it can identify and process the relevant command or feature.

Comet does not intentionally maintain a permanent history of normal messages, prefix commands, or general message activity.

5. Storage

Comet is designed around minimal storage.

Comet does not intentionally maintain a permanent database of users, messages, normal command usage, or general member activity.

Some features may temporarily keep information in Comet's memory while they are operating. For example, PingWarn may temporarily keep settings and ping counts, while commands may temporarily keep cooldown information.

Temporary information is removed when it is no longer needed or when Comet restarts. These temporary features are not intended to become permanent activity records.

Comet's own configuration and credentials may be stored securely on the system running the bot. These are configuration details rather than a database of user activity.

6. Moderation

When authorised moderation features are used, Comet processes the information required to carry out the requested moderation action.

Where the server uses a designated Discord channel or forum for moderation records, information about moderation actions may be posted there for staff to review.

These moderation records are intentional Discord server records and may remain there according to the community's moderation practices.

Comet does not maintain a separate permanent moderation database for this purpose.

7. What Comet Does Not Intentionally Do

  • Sell user information
  • Use user information for advertising
  • Build a permanent general-purpose member database
  • Keep a permanent history of normal command usage
  • Track users across unrelated services
  • Collect information from unrelated websites for profiling
  • Store information that is not needed for a Comet feature

Comet is intended to process the minimum information reasonably needed for the features it provides.

8. Discord and the Discord API

Comet operates through Discord and the Discord API. Information provided to Comet through Discord is processed by Comet only as needed for its features.

Discord independently processes information as part of providing the Discord platform. Comet does not control or determine Discord's independent processing of information.

For more information about Discord's own processing and privacy practices, see:

Discord Privacy Policy

9. Security

Reasonable measures are used to protect Comet's configuration and credentials from unauthorised access.

Comet's bot credentials are kept private and are not intentionally shared with other users.

10. Changes to Comet

Comet may gain, lose, or change commands and features over time. Individual commands do not normally require this privacy notice to be updated when they continue to process information in the ways described above.

This notice will be reviewed and updated if Comet introduces a genuinely different type of data collection, storage, sharing, or use that is not reasonably covered by this notice.

11. Questions

If you have a question about Comet's data handling or how a particular feature works, you can contact the person maintaining Comet through the Discord community where Comet is used.
