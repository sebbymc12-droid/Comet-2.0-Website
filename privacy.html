Privacy Policy

Last Updated: 12 September 2026

1. Information Comet Can Access

Comet 2.0 is designed with privacy and data minimisation in mind. The bot aims to process only the information necessary to provide its features and to avoid permanently storing information about Discord users.

Depending on the features being used, Comet may temporarily access:

  • Discord user IDs, usernames, display names and avatars
  • Server membership and role information
  • Information required to process commands
  • Message metadata and mention information where required for PingWarn
  • Moderation information necessary to perform moderation commands

Comet only accesses information required for its functionality.

2. Message Content

Comet does not operate as a message scraper or message archive.

Comet does not request or use Discord's Message Content Intent. PingWarn is designed to operate using mention information and other necessary message metadata rather than reading the actual text of Discord messages.

Comet does not intentionally save, archive, sell, use for advertising or profiling, or send Discord message content to unrelated external services.

Because Message Content Intent is not enabled, Comet is not designed to access the full text of ordinary Discord messages.

3. PingWarn Data

PingWarn may temporarily process information such as:

  • The Discord ID of a protected user
  • The configured warning threshold
  • A temporary mention count
  • Timestamps required for the configured decay period

Temporary PingWarn information is automatically removed when it is no longer required.

Expired PingWarn counters are reset rather than retained as historical records.

When a PingWarn threshold results in a formal warning, Comet may create a limited moderation record in the server's designated private Staff Hub moderation Forum if one is configured. This record may contain information such as the pinger, protected user, ping count, server, channel and action taken.

The original message content is not included in the PingWarn moderation record.

4. Moderation Data

Comet's moderation commands may create moderation records in the configured Discord moderation Forum.

Comet is designed not to maintain a separate permanent database containing users' moderation histories.

Information required to perform a moderation action may be processed temporarily by Comet, while the resulting moderation record may remain in the Discord server's designated moderation Forum according to that server's own retention practices.

5. Data Storage

Comet follows a data-minimisation approach.

Comet does not intentionally maintain a permanent database of:

  • General Discord conversations
  • User activity histories
  • User profiles
  • Message histories
  • PingWarn histories after they are no longer required
  • Unnecessary personal information

Where information only needs to exist temporarily, Comet aims to keep it in memory and discard it as soon as it is no longer needed.

6. Data Retention

Comet does not intentionally retain information indefinitely.

Temporary information is deleted when the relevant feature no longer requires it.

PingWarn counters are removed when their configured decay period expires or when they are otherwise no longer needed.

Information stored directly by Discord, including messages or moderation Forum posts created through Comet, is subject to Discord and the relevant server's own retention practices and is not controlled entirely by Comet.

7. Data Sharing

Comet does not sell personal information or share user information with advertisers or data brokers.

Comet does not intentionally send Discord message content or user information to unrelated third-party services.

Discord's own services are necessarily involved when Comet interacts with Discord.

8. Discord

Comet operates through Discord's platform and Discord's APIs.

Information processed by Comet may therefore also be processed by Discord according to Discord's own policies and terms.

9. Data Security

Reasonable measures are used to protect Comet's configuration and stored files.

The bot's authentication token is kept separately from the public source code and is not intentionally committed to public repositories.

10. Data Requests

Because Comet is designed to minimise permanent storage, Comet may have little or no retained information relating to an individual user outside of records maintained by Discord or the server using the bot.

If you have any questions, concerns or requests regarding Comet 2.0 or this policy, please contact @comet_saturn through Discord.

11. Changes

This Privacy Policy may be updated when Comet's functionality or data practices change.

The latest version will be made available through the Comet 2.0 website.

12. Contact

If you have any questions, concerns or requests regarding Comet 2.0 or this Privacy Policy, please contact @comet_saturn through Discord.
