Comet 2.0 Privacy

Last updated: 6 October 2026

1. TL;DR

Comet 2.0 is a personal Discord bot and passion project created and maintained by @comet_saturn.

Comet is provided free of charge and is primarily intended to provide fun, games, and lightweight entertainment features on Discord.

Comet is designed around data minimisation. It does not intentionally maintain a permanent database of users, messages, or normal command activity.

2. What Comet May Process

Comet operates through the Discord API. Discord may provide Comet with information required for the bot to function.

Depending on how Comet is being used, this may include:

  • Discord user IDs, usernames, and display information
  • Server and channel information
  • Command names and command options
  • Information provided directly as part of a command
  • Information temporarily required to operate an active game
  • Other Discord-provided information reasonably necessary for an enabled feature

Comet's current command set consists primarily of fun, random, game, and entertainment commands. The exact information available to Comet depends on the Discord feature being used.

3. Why Comet Uses This Information

Information is processed only as reasonably necessary to provide Comet's features and respond to users.

This can include:

  • Processing slash commands
  • Sending command responses
  • Running games such as Tic-Tac-Toe and Connect 4
  • Generating random or entertainment responses
  • Checking information required to operate a command
  • Maintaining temporary state while a feature is active

Comet does not intentionally use this information for advertising, behavioural profiling, or unrelated purposes.

4. Messages and Command Input

Comet primarily uses Discord application commands, such as slash commands, but also supports prefix commands beginning with c!.

When prefix commands are enabled, Comet may temporarily read message content in order to identify and process commands beginning with c!.

Comet may also receive message information required for features such as games, command responses, and message-related functionality.

Comet does not intentionally maintain a permanent history of normal Discord messages, prefix commands, or general message activity.

5. Games and Temporary Data

Some Comet commands require temporary information to remain in memory while a feature is being used.

For example, games such as Tic-Tac-Toe and Connect 4 may temporarily keep information such as the participating users, board state, and the current game status.

This information exists to operate the active game and is not intended to form a permanent player database or activity history.

Temporary in-memory information may be lost when a game ends or when Comet restarts.

6. Storage

Comet is designed around minimal storage.

Comet does not intentionally maintain a permanent database of users, messages, normal command usage, or general member activity.

Temporary information may exist in Comet's memory while commands or games are being processed. This information is not intended to be retained as a permanent user record.

Comet's configuration and bot credentials may be stored securely on the system running the bot. These are operational configuration details and are not a database of user activity.

7. What Comet Does Not Intentionally Do

  • Sell user information
  • Use user information for advertising
  • Build a permanent general-purpose member database
  • Maintain a permanent history of normal command usage
  • Track users across unrelated services
  • Profile users for advertising or behavioural purposes
  • Collect information that is not reasonably needed for a Comet feature

Comet is intended to process the minimum information reasonably necessary for the features it provides.

8. Discord and the Discord API

Comet operates through Discord and the Discord API. Information provided to Comet through Discord is processed only as needed for Comet's features.

Discord independently processes information as part of providing the Discord platform. Comet does not control Discord's independent processing of information.

For more information about Discord's own privacy practices, see:

Discord Privacy Policy

9. Security

Reasonable measures are used to protect Comet's configuration and bot credentials from unauthorised access.

Comet's bot credentials are kept private and are not intentionally shared with other users.

No method of transmitting or storing information can be guaranteed to be completely secure. Comet is a small personal project and is operated with reasonable security measures appropriate to its limited scope.

10. Data Requests

Because Comet does not intentionally maintain a permanent general-purpose database of users or normal command activity, there may be no persistent user data for Comet to retrieve, correct, or delete.

If you believe Comet is retaining information about you or you have a question about a particular feature, you can contact the person maintaining Comet through the Discord community where Comet is used.

11. Changes to Comet

Comet may gain, lose, or change commands and features over time.

This privacy notice will be reviewed and updated when Comet introduces a materially different type of data collection, storage, sharing, or use that is not reasonably covered by this notice.

The date at the top of this page indicates when this notice was most recently updated.

12. Questions

If you have a question about Comet's data handling or how a particular feature works, you can contact the person maintaining Comet through the Discord community where Comet is used.
