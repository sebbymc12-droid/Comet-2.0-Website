Comet 2.0 Privacy

Last updated: 17 September 2026

1. About Comet

Comet 2.0 is a personal Discord bot and passion project created and maintained by @comet_saturn.

Comet is currently used for a single Discord community and is provided free of charge. It is not intended to be a commercial service, and there is currently no intention to charge users for using Comet.

Comet may be discontinued or changed in the future.

2. How Comet Works

Comet operates through the Discord API.

Information that Comet needs to perform its functions is provided to it by Discord through the Discord API. Comet then sends the required actions, responses, messages, or moderation actions back through Discord.

Comet does not independently collect information from unrelated websites or services.

3. Information Comet May Process

Depending on the command or feature being used, Comet may temporarily process information such as:

  • Discord user IDs
  • Discord usernames and display information
  • Server, channel, role, and message information needed for a command
  • Command options and arguments
  • Information required to perform moderation actions
  • Information required to operate PingWarn
  • Other information Discord provides to the bot that is necessary for its enabled features

Comet only uses this information for the functions and commands it is designed to provide.

4. Prefix Commands

Comet supports prefix commands beginning with c!.

When a prefix command is used, Comet temporarily reads the message content so it can identify the command and its arguments.

Comet does not intentionally keep a permanent history of prefix commands or message content.

5. PingWarn

PingWarn may temporarily keep information in Comet's memory while the feature is enabled, such as:

  • The protected user's Discord ID
  • Ping thresholds
  • Ping counts
  • Automatic-warning settings
  • Count-decay settings
  • Information needed to determine whether a ping should trigger a warning

This information is kept in memory for PingWarn's functionality and is cleared when it is no longer needed or when Comet restarts.

PingWarn does not use a permanent database for general user activity.

6. Temporary Command Information

Some commands need temporary information while they operate.

For example, a cooldown may temporarily remember that a user recently used a command.

This information is kept only for the feature to work and is not intended to become a permanent record of user activity.

7. Moderation

When moderation commands such as warnings, kicks, mutes, bans, or purges are used, Comet may process the information required to carry out and record that moderation action.

Where a moderation record is required, the record is created through Discord, such as in the server's designated moderation channel or forum.

Comet may also keep a small case-number counter so that moderation cases can have unique case numbers. This counter does not contain a history of users, messages, or general activity.

Moderation records created in Discord are intentional server records and may remain there according to the server's moderation practices.

8. What Comet Does Not Intentionally Do

Comet does not intentionally:

  • Sell user information
  • Use user information for advertising
  • Build a general-purpose database of server members
  • Keep a permanent history of normal command usage
  • Track users across unrelated servers or services
  • Collect information from unrelated websites for profiling
  • Store information that is not needed for one of its functions

Comet is designed to process the minimum information reasonably needed for its commands and features.

9. Discord and the Discord API

Comet relies on Discord and the Discord API to operate.

Discord independently processes information as part of providing the Discord platform. That processing is governed by Discord's own policies and privacy practices.

Comet does not control information that Discord processes independently of the bot.

You can read Discord's current Privacy Policy here:

Discord Privacy Policy

10. Security

Reasonable measures are used to prevent unnecessary access to Comet's configuration and information.

Comet's bot credentials are kept private and are not intentionally shared with other users.

11. Questions

If you have a question about what Comet processes or how a particular feature works, you can contact the person maintaining Comet through the Discord community where Comet is used.

12. Changes

This notice may be updated if Comet's features, data handling, or how the bot operates changes.

The date at the top of this page will be updated when significant changes are made.
