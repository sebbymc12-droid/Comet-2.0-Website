Privacy Policy

Last Updated: 17 September 2026

1. About Comet 2.0

Comet 2.0 ("Comet", "the bot", "we", "us" or "our") is a Discord bot operated by @comet_saturn. Comet provides server management, moderation, SSU management, PingWarn and general-purpose commands.

Comet is designed with privacy and data minimisation in mind. The bot aims to process only the information necessary to provide its features and avoids intentionally maintaining permanent user activity histories or message archives.

2. Information Comet May Process

Depending on the features being used, Comet may temporarily process information made available through Discord, including:

  • Discord user IDs
  • Discord usernames and display names
  • Discord server, channel and role information
  • Information required to process commands
  • Message content when required for a c! prefix command
  • Message mention information required for PingWarn
  • Information required to perform moderation actions
  • Temporary timestamps used for cooldowns and PingWarn

Comet only processes information that is relevant to the feature being used. Comet does not intentionally collect unrelated personal information.

3. Message Content and Prefix Commands

Comet supports commands beginning with the c! prefix, such as c!ping and c!dice.

To provide this functionality, Comet uses Discord's Message Content Intent. This allows Comet to temporarily receive and inspect message content so it can determine whether a message contains a Comet prefix command and process any command arguments.

Comet does not intentionally use this access to create a message archive, conversation history, user activity profile, advertising profile or analytics history.

Message content received for prefix-command processing is not intentionally written to a permanent Comet database or file. It is used for processing the relevant command and is not intentionally retained as a historical record.

Discord controls access to Message Content Intent through its own platform and developer requirements. Comet's use of the intent is limited to the functionality described in this policy.

4. PingWarn

PingWarn is a temporary protection feature that can warn or take a configured moderation action when a protected user is repeatedly mentioned.

PingWarn may temporarily process:

  • The Discord ID of the protected user
  • The configured warning threshold
  • A temporary mention count
  • Timestamps required for the configured decay period
  • The Discord role used to identify PingWarn protection

PingWarn configuration and counters are held in Comet's active memory. They are not intentionally written to a permanent database or file.

PingWarn information is cleared when Comet restarts. Counters are reset when their configured decay period has expired rather than being retained as historical activity.

When PingWarn results in a formal moderation action, Comet may create a limited moderation record in the server's designated private Staff Hub moderation Forum, if configured.

A PingWarn moderation record may contain information such as the pinger, protected user, ping count, server, channel and action taken.

The original message content is not intentionally included in the PingWarn moderation record.

5. Temporary Command Cooldowns

Some commands use temporary cooldowns to prevent excessive or repeated use.

For example, the beg command uses a 15-minute per-user cooldown.

To enforce a cooldown, Comet temporarily keeps the relevant Discord user ID and a timestamp in memory.

Cooldown information is not intentionally written to a permanent database or file and is cleared when Comet restarts.

Cooldown information is used only to enforce the relevant command restriction and is not used to build a user activity history.

6. Moderation Information

Comet's moderation commands may temporarily process information necessary to perform a requested moderation action.

This may include:

  • The affected user's Discord ID and username
  • The moderator's Discord ID and username
  • The server where the action occurred
  • The relevant channel
  • The moderation reason
  • Information required to perform the requested action

Where configured, Comet may create a moderation record in the server's designated private moderation Forum.

These Forum records are intentional moderation records stored through Discord. They are not a separate Comet database and may remain available according to the server's own moderation and retention practices.

Comet does not intentionally maintain a separate permanent database containing a user's complete moderation history.

7. What Comet Does Not Intentionally Store

Comet does not intentionally maintain a permanent database of:

  • General Discord conversations
  • Message histories
  • Command usage histories
  • User activity histories
  • User profiles created for tracking or profiling
  • PingWarn history after it is no longer required
  • Command cooldown histories
  • Unnecessary personal information

Temporary information required for a feature is kept in active memory rather than being intentionally converted into a permanent activity record.

8. Data Retention

Comet's general approach is to retain temporary information only for as long as it is required for the relevant feature.

  • Prefix-command message content is processed temporarily for the relevant command and is not intentionally retained as a historical record.
  • PingWarn configuration and counters are held in memory and are cleared when Comet restarts. Expired counters are reset rather than retained as historical activity.
  • Command cooldown information is held temporarily in memory and is cleared when Comet restarts.
  • Moderation Forum records may remain in Discord according to the server's own retention practices.

Because some information is held only in memory, Comet may not have historical information available to provide after the relevant temporary processing has ended or after the bot has restarted.

9. Data Sharing and Third Parties

Comet does not sell personal information.

Comet does not intentionally share user information with advertisers or data brokers.

Comet does not intentionally send Discord message content or user information to unrelated third-party services for advertising, profiling or analytics.

Comet necessarily communicates with Discord and uses Discord's APIs to provide its functionality. Information made available through Discord may therefore be processed by Discord according to Discord's own terms and privacy practices.

10. Discord and Platform Data

Comet operates through Discord's platform and APIs.

Discord independently controls its own platform, systems, infrastructure, logging and data processing. Comet does not control information that Discord retains independently of Comet.

This includes messages, Discord account information, server information and moderation Forum content stored by Discord.

11. Security

Comet is designed to minimise the amount of information it retains and to avoid unnecessary persistent storage.

Comet's authentication token is kept separately from its source code and is not intentionally committed to public repositories.

Access to Comet's configuration and hosting environment is restricted to the people responsible for operating the bot.

No method of transmission or storage can be guaranteed to be completely secure. Comet's security measures are intended to reduce unnecessary exposure rather than provide an absolute guarantee of security.

12. Your Privacy Rights

Depending on the circumstances and the applicable data protection law, individuals may have rights concerning their personal information. These may include rights to request access, correction, deletion, restriction or objection to processing.

The availability of a particular right depends on the circumstances and the lawful basis for the relevant processing.

Because Comet intentionally retains very little information, there may be no Comet-held information available to provide, correct or delete when a request is received.

Information stored directly by Discord, including Discord messages or moderation Forum records, may need to be managed through Discord or the relevant server's administrators rather than through Comet.

13. Data Protection Contact

For questions, concerns or requests about Comet 2.0's handling of information, contact @comet_saturn through Discord.

If you are contacting us about a specific Discord server, please include enough information for us to understand which Comet feature or processing activity your request concerns.

More information about making a complaint is available from the ICO's official website.
